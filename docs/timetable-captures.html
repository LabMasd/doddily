Little Days

Timetables to capture

These classes and groups run at a venue we know about, but their websites don’t let automated readers collect the times. A quick screenshot from you gets them into the app. Claude reads the days, times, prices and ages from each one.

    How it works

    1. Open a page and find the class times: the lesson list, timetable or “book a class” table.
    2. Screenshot the times (⌘ ⇧ 4, then drag) and name the file after the listing code, e.g. WB-014.png. If one page covers several listings, one screenshot named after the first code is enough.
    3. Save it in ~/Desktop/little-days-captures and tick the listing. If a page shows no classes, save it as WB-014-none.png so the listing can be hidden.
    4. After a batch, tell Claude “captures ready”.
